\textit{Tomato leaf diseases can reduce crop quality and productivity when they are not identified early. Image classification based on deep learning can help identify these diseases more quickly and consistently. However, a model deployed on an edge device must not only provide good accuracy, but also remain lightweight and efficient on limited hardware. This study aims to compare the performance of YOLOv8 Nano and YOLO11 Nano in edge-based tomato leaf disease classification, and to determine which model is more suitable based on accuracy and inference efficiency.}

\textit{The dataset consists of 7,200 tomato leaf images divided into six classes: Tomato Early Blight, Tomato Healthy, Tomato Leaf Late Blight, Tomato Leaf Yellow Curl Virus, Tomato Mold Leaf, and Tomato Septoria Leaf Spot. Both models were trained using the same configuration with 20 seed variations, exported to ONNX format, and tested on a Raspberry Pi 5 using 720 balanced test images. The results show that YOLOv8 Nano achieved an average accuracy of 88.32\%, while YOLO11 Nano achieved 87.81\%. Based on the Wilcoxon Signed-Rank test, the difference was not statistically significant, with a p-value of 0.2706.}

\textit{In terms of efficiency, YOLOv8 Nano recorded an inference time of 8.430 ms, a total pipeline time of 9.794 ms, 102.29 FPS, and a model size of 5.531 MB. YOLO11 Nano recorded 8.502 ms, 9.848 ms, 101.72 FPS, and 5.895 MB. These results indicate that both models have comparable classification performance, but YOLOv8 Nano is more suitable for edge deployment because it is lighter and slightly faster.}
