\textit{Tomato leaf diseases can reduce crop quality and productivity if they are not identified at an early stage. One approach that can support disease identification is image classification using \textit{deep learning}. However, a model deployed on an \textit{edge} device should not only provide good accuracy, but also remain lightweight and efficient on hardware with limited computational resources. This study aims to compare the performance of YOLOv8 Nano and YOLO11 Nano in classifying tomato leaf diseases on an \textit{edge} device. The dataset used in this study consists of 7,200 tomato leaf images divided into six classes: Tomato Early Blight, Tomato Healthy, Tomato Leaf Late Blight, Tomato Leaf Yellow Curl Virus, Tomato Mold Leaf, and Tomato Septoria Leaf Spot. Both models were trained using the same configuration and evaluated on a balanced test set containing 720 images. The results show that YOLOv8 Nano achieved an accuracy of 88.47\%, a macro F1-score of 88.63\%, an average inference time of 7.78 ms, and 128.52 FPS on Raspberry Pi 5. Meanwhile, YOLO11 Nano achieved an accuracy of 88.06\%, a macro F1-score of 88.12\%, an average inference time of 7.86 ms, and 127.18 FPS. Based on these results, YOLOv8 Nano showed slightly better performance than YOLO11 Nano in this research scenario. Although the difference was small, this study highlights the importance of directly evaluating models on the target dataset and device before selecting the most suitable model for edge-based implementation.}
